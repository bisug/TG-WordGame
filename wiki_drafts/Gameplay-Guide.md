# Gameplay Guide

WordSeek is a word-guessing game where you find a hidden word within a limited number of attempts.

## Basic Rules
1. **Start a Game**: Use `/new`, `/new4`, `/new5`, or `/new6`.
2. **Make a Guess**: Send your guess (e.g., `APPLE`) in the chat.
3. **Hints**: After each guess, the bot provides color-coded feedback:
   - 🟩 **Green**: Correct letter in the correct position.
   - 🟨 **Yellow**: Correct letter but in the wrong position.
   - 🟥 **Red/Gray**: Letter is not in the word.

## Game Modes

### 1. Normal Game
Available in private and group chats.
- **4 Letters**: `/new4`
- **5 Letters**: `/new5` (Default)
- **6 Letters**: `/new6`

### 2. Daily WordSeek
Private chat only.
- Use `/daily` to start the daily challenge.
- Everyone gets the same word globally.
- Use `/pausedaily` to switch back to normal games.

### 3. Multiplayer (Groups)
- Any member can participate.
- The first correct guess wins the round.
- Scores are tracked in group and global leaderboards.

## Scoring
- `/score`: View personal stats.
- `/leaderboard`: View top rankings.

## Tips
- Start with common vowels (A, E, I, O, U) and consonants (R, S, T, L, N).
- Use previous hints to narrow down options.
- Collaboration in group chats makes games faster.

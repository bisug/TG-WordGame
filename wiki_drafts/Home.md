# Welcome to the WordSeek Wiki

WordSeek is a high-performance Telegram Word Game bot inspired by Wordle. This wiki provides comprehensive documentation for players and developers.

## Quick Links
- **Playing the Game**: See the [[Gameplay Guide]].
- **Bot Setup**: Follow [[Getting Started]] for installation.
- **Commands**: Complete [[Commands Reference]].
- **Deployment**: Hosting instructions in [[Deployment Guide]].

## Features
- **Multi-Length Modes**: 4, 5, or 6-letter words.
- **Daily WordSeek**: Unique daily challenge in private chats.
- **Multiplayer**: Group competition support.
- **Leaderboards**: Global and group rankings.
- **Forum Support**: Specialized Telegram Forum topic settings.

## Tech Stack
- **Bun.js**: JavaScript runtime.
- **grammY**: Bot framework.
- **PostgreSQL**: Relational database.
- **Redis & BullMQ**: Caching and job queues.
- **Kysely**: Type-safe SQL query builder.
